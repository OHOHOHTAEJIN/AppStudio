# 모자이크 가드·근무페이 실기기 QA 체크리스트

## 공통

- Android 12/13/14/15/16에서 설치·실행·권한 요청 확인
- 휴대폰 화면, 접이식 기기, 태블릿 세로·가로 전환, 글꼴 150%에서 잘림 확인
- 신규 아이콘 및 앱별 고유 패키지 ID 확인
- 앱 종료 후 재진입, 공유 메뉴 취소, 갤러리 접근 취소·거부 시 오류 없음 확인

## 모자이크 가드

- 밝은 사진·인물 여러 명·측면 얼굴에서 자동 얼굴 영역이 실제로 표시되는지 확인
- 차량번호·문서의 한글·전화번호를 문자 후보로 감지하는지 확인(감지 누락 가능)
- 손가락으로 세로·가로 직사각형을 직접 지정하고 취소·복원 확인
- 모자이크/흐림/검정 가림의 **실제 결과 JPEG 픽셀**을 확인
- 가린 결과물 공유, 원본 이미지가 변경되지 않았는지 확인
- 내보낸 JPEG에서 EXIF 위치정보가 없는지 메타데이터 도구로 검증
- 큰 원본(20MP 이상)의 축소 안내 및 처리속도/메모리 영향 확인
- 얼굴·문자 자동 감지 실패 시 수동 가리기 가능한지 확인

## 근무페이

- 한 달에 30회 이상 기록 생성/수정/삭제 및 앱 재시작 후 데이터 유지
- 09:00~18:00, 휴게60분 → 8시간·기본급 확인
- 22:00~06:00, 휴게60분 → 익일 퇴근·7시간·야간 시간 추정 확인
- 휴게0, 휴게 > 근무시간, 퇴근=출근, 수정 후 월 이동 확인
- 가산수당 옵션 OFF/ON 각각 계산, 사용자 시급 수정 및 월별 수당 조정 확인
- CSV Excel/스프레드시트 한글 깨짐 여부, 날짜·개근월·금액 데이터 일치
- 날짜가 달을 넘는 근무가 **출근일의 달**에 포함되는 정책 확인
- 주휴·휴일수당·주 40시간 초과·세금·보험은 **자동 법정 판정하지 않음** 명시 확인

## 출시 전 필수

- 개인정보처리방침, 저장·삭제 정책 고지, AdMob 및 UMP(동의) 확인
- 릴리스 서명 AAB, Play Console 정책, 스토어 소개 이미지/스크린샷
- 급여 계산기 법령 관련 문구의 최신성 및 노동법 전문가 검토
