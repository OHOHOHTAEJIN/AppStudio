# AppStudio 기능 상태 (v0.2.0, 2026-11-14)

## 이번 변경(작업 브랜치)
- 공통 UI: 반응형 화면 폭, 컴팩트 통계 카드, 그라데이션 히어로, 섹션 제목·안내 메시지
- 펄스 퍼즐: 30초/60초/20단계 모드, 쉬움/보통/어려움, 일시정지, 모드별 최고 기록
- 픽셀 슬림: 사진 최대 20장 일괄 JPEG 압축, 크기·화질 조절, 변환 결과 공유, Media3 기반 동영상 압축 480/720/1080p·취소·진행률
- 도큐 스냅: 사진 순서 변경·삭제, 흑백 대비 보정 후 A4 PDF, 파일명 지정, 한국어/라틴 문자 OCR, 결과 복사
- 데일리 퀴즈: 90문제, 오늘의 퀴즈 및 분야별 연습, 정답 시각 강조·해설, 참여일·최고 점수 저장

## 검증 기준
- 소스 반영과 빌드 성공은 실기기 동작 검증이 아님
- 플러그인의 실제 동영상 압축, 카메라, 사진 공유, OCR 정확도는 실기기/에뮬레이터 통합 테스트가 별도 필요
- Android APK는 AppStudio 전용 Windows runner에서 빌드하여 GitHub Actions artifact로 업로드
- 사용자 데이터는 기본적으로 기기에서 처리 (ML Kit 네이티브 라이브러리는 포함)

- 퍼즐 추가 업적·보상·사운드 등 고급 요소
